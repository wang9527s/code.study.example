# CPU 执行循环

CPU 是一个无限循环：**取指令(pc 指向的地址) → 译码 → 执行 → pc 自动指向下一条**，重复。所谓"跳转"，本质就是**修改 pc**。

## 寄存器

| 寄存器 | 别名 | 作用 |
|--------|------|------|
| `pc` | Program Counter | 下一条指令地址，改它就是"跳转" |
| `sp` | Stack Pointer | 栈顶地址 |
| `lr` (x30) | Link Register | 存"跳转目标地址" |
| `fp` (x29) | Frame Pointer | 当前栈帧底部 |
| `x0-x7` | 参数/临时 | 传参、返回值 |
| `x19-x28` | Callee-saved | 跨函数调用不丢失 |

### lr 的两种用法

`ret` 只做一件事：`pc = lr`。它不关心 lr 里的地址是哪来的。

- **正常函数调用**：`bl foo` 自动写 lr = 返回地址，`ret` 读 lr 回到调用点
- **协程切换**：手动塞 lr（从 Context 结构体恢复），`ret` 跳到目标协程上次暂停的位置。跟 `bl`/`ret` 配对无关，本质是把 `ret` 当无条件跳转用
